# Prince Bhamla — Portfolio

Interactive 3D developer portfolio showcasing full-stack web applications, voice-enabled systems (such as **Voice Khata**), and Three.js spatial telemetry.

## Features
- **3D Spatial Telemetry**: Interactive Three.js telemetry globe with smooth 360° drag controls.
- **Voice Khata Spotlight**: Interactive audio processing unit and simulated voice query transcription.
- **Project Carousel**: Touch, drag, and swipe enabled project slider with active dot pagination.
- **Categorized Skills**: Clean matrix for Frontend, Backend, AI/ML, and Tooling.
- **Responsive & Accessible**: High-performance 60 FPS rendering on modern browsers and mobile devices.

## Tech Stack
- **Languages**: HTML5, CSS3, JavaScript (ES6+)
- **Libraries**: Three.js (r128), Google Fonts
- **Deployment**: GitHub Pages / Vercel

## Local Development
Simply open `index.html` in any web browser or serve locally:
```bash
npx serve .
```
